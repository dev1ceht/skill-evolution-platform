# ADR-003：食品安全与运营治理事实模型

Status: Accepted

## 背景

阶段2已经建立食谱、采购计划、采购订单、验收入库、库存批次和溯源事实。阶段3需要补齐台账和合规治理，但不能通过第二套采购、库存或预警状态制造平行事实。

## 决策

- 所有阶段3记录都带 `schoolId + canteenId` 范围；范围过滤由存储层和应用层共同保证。
- 台账配置定义要求和周期，台账记录仍沿用已有台账事实与预警同步机制。
- 合规档案的提交、审核、更新追加历史；有效期扫描使用统一 `AlertCenter`，预警键由档案标识和有效期组成。
- 已发布食堂风采、已批准合规档案和已关闭投诉不允许静默覆盖；任何修改必须产生新版本或显式状态转换。
- 对象存储、OCR、短信、微信和外部设备仅保留稳定适配边界，未配置凭据时不宣称外部能力可用。

## 后果

在不依赖外部系统凭据的情况下，可以真实验证阶段3的业务规则、持久化和审计链路；后续接入外部能力时只替换适配器，不改变核心状态机。
