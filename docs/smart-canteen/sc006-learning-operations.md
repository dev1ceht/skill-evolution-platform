# SC-006 学习环境运行与退役记录

## 适用范围

SC-006 是个人学习环境中的“已发布菜单原料缺口只读分析”切片。它使用仓库内的 study dataset 或测试数据，不连接真实 POS、ERP、供应商或采购系统，因此本文记录的是可复现的本地健康与漂移边界，不是生产 SLO 承诺。

## 健康检查

- Java 全量测试：236 tests，0 failures，0 errors，2 skipped。
- Python SOP/契约测试：20 passed；SOP manifest 为 10 个 SOP、1 个组合运行。
- Flyway：30 个迁移可在 H2 测试库完成校验与执行，包含 V30 `PROCUREMENT_ANALYSIS_READ` 权限。
- 端到端样例：自然语言请求经过 Assistant Runtime、Skill 和 `procurement.gap.query`，返回菜单、Recipe/BOM、库存和缺口事实；验证没有新增采购计划。

## 漂移与失败回灌

当前需要在后续学习迭代中观察并回灌的样例：

1. 日期无已发布菜单：返回空分析，不猜测备餐量。
2. 已发布菜单引用不存在或停用的菜品/原料：业务服务失败，保留 Run 失败状态，不能由模型补事实。
3. Recipe/BOM 单位与食材基准单位不兼容：返回确定性校验错误，不能自动换算。
4. 模型无法识别请求：回退规则解析器；模型不能直接选择写 Tool。
5. 学习数据与未来真实系统字段不一致：接入真实服务前重新校验适配器、权限和单位语义。
