# ADR-002：采购计划保存食谱与库存计算快照

## 状态

Accepted for Phase 2.

## 背景

采购计划由未来已发布食谱、现有库存和未入库采购订单计算。食谱、库存和订单都会在计划生成后继续变化；如果计划只保存一个可重新计算的查询条件，人工调整和审计无法还原当时为什么得到这个采购量。

## 决策

采购计划保存：

- 日期区间和来源日食谱 ID；
- 每种食材的需求基础量、生成时库存量、未入库订单量和建议采购量；
- 人工调整后的计划量和版本号；
- 计划到采购订单的关联。

计划一旦确认，后续食谱或库存变化不回写计划；重新生成会创建新的幂等计划。采购订单和验收入库继续引用同一食堂范围内的食材基础单位和批次事实。

## 后果

优点是计划可审计、可人工调整、可重试，且订单转化不会因实时库存变化而改变已经确认的采购承诺。代价是计划可能在确认时已过时，因此后续可增加“重新校验库存”的显式动作，但不能隐式修改已确认计划。
